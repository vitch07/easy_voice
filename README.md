# Easy Voice 🎙️📱

Easy Voice is an innovative app prototype developed using **Flutter & Dart** that empowers elderly and physically challenged users to access **YouTube** through **voice commands**. The app is designed to filter out irrelevant speech inputs and provide **accurate video searches** based on user intent, making video content more accessible and user-friendly.

---

## 🧠 Key Features

- 🎤 **Voice-Activated Search**: Enables users to search YouTube hands-free using voice commands.
- 🧹 **Smart Filtering**: Filters out filler words and irrelevant phrases to improve search accuracy.
- 🔍 **Accurate Video Results**: Parses processed voice input to return relevant and targeted video suggestions.
- 🧓 **Accessibility Focused**: Tailored for elderly and physically challenged users to minimize interaction complexity.
- 💡 **Prototype UI**: Clean and intuitive user interface designed with accessibility in mind.
